AI 영상 피드백 자동 개선 시스템

만들고 싶은 영상을 한두 문장으로 적으면 로컬 AI가 장면을 짜고 영상으로 만든 뒤 스스로 점검해 다시 만듭니다. YouTube에 올린 뒤에는 시청자 댓글 가운데 건설적인 의견만 골라 묶고, 제작자가 승인한 의견을 다음 버전에 반영해 지적받은 장면만 다시 만듭니다.

  • 2번사람의 확인

    처음 설명과 마지막 확인만 합니다. 나머지는 AI가 처리합니다.

  • 0개필요한 외부 계정

    영상·이미지·음악·번역·분류 모두 로컬 GPU/CPU에서 돌아갑니다.

  • 장면 단위부분 재생성

    지적받은 장면만 다시 만들고, 소리·편집 의견은 합성에만 반영합니다.

전체 흐름

기획부터 시청자 의견까지 한 바퀴를 돌면 다음 버전이 나옵니다. 사람은 빨간 지점에서만 개입합니다.

AI가 처리사람이 확인·결정다음 버전

AI 자동 진행 — 장면 하나가 만들어지는 과정

이미지를 먼저 그리고 그 이미지를 움직입니다. 단계마다 비전 모델이 결과를 보고, 기준에 못 미치면 고칠 문장을 붙여 다시 만듭니다(장면당 최대 2번).

시청자 의견을 반영하는 방법

모든 의견에 장면을 다시 만들지 않습니다. 의견이 어디를 고치라는 것인지(반영 위치)에 따라 가장 싼 방법으로 반영합니다.

장면을 다시 만듦 (GPU)장면을 다시 만들지 않음

지키는 원칙

  • AI가 화면에 글자를 만들지 않게 한다제목·로고·자막은 편집에서 합성하고, 자막은 영상에 굽지 않고 .srt로 올립니다.
  • 사람의 확인을 줄이고 AI가 대부분 처리한다AI가 답하지 못하는 점검은 통과로 두고 멈추지 않습니다. 끝까지 미달이면 가장 나은 버전과 "확인 필요"를 남깁니다.
  • 외부 계정 없이 동작한다YouTube 업로드와 Claude API는 키가 있을 때만 선택적으로 씁니다. 업로드는 사람이 버튼을 눌러야만 합니다.
  • 상태 전이는 한 곳에서만기획 → 제작 → 확인 → 공개 → 의견 → 승인 → 다음 버전, 9단계 상태 머신을 오케스트레이터 하나가 관리합니다.

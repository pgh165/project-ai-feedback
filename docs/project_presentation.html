영상 자동 생성

한두 문장의 설명으로 AI가 장면을 짜고, 첫 프레임을 그린 뒤 컷 영상을 만듭니다. 단계마다 비전 모델이 품질을 점검합니다.

추린다

01
AI가 화면에 글자를 만들지 않습니다

영상 모델이 그린 글자는 깨지고, 한글은 특히 심합니다. 그래서 제목·로고는 편집에서 합성하고, 자막은 YouTube 자막(.srt)으로 올립니다.

02
사람의 확인을 최소화합니다

점검과 다시 만들기를 AI가 끝까지 이어서 합니다. 끝까지 기준에 못 미친 장면은 가장 나은 버전을 넣고 "확인 필요"로 표시합니다.

03
AI는 전부 로컬에서 동작합니다

영상·이미지·판단 AI는 그래픽카드 1장짜리 컴퓨터에서 돌고, 유료 API를 쓰지 않습니다. YouTube는 영상 공개와 댓글 수집에만 씁니다.

04
중간에 멈춰도 이어서 만듭니다

진행 단계와 작업 기록을 저장해 두므로, 서버가 꺼져도 이미 만든 장면은 남고 '재시도'로 나머지만 만듭니다.
